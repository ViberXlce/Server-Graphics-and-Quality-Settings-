# Server Graphics and Quality Settings (Fabric 1.21.11)

اضغط **P** داخل اللعبة لفتح شاشة الإعدادات.

## البناء عن طريق GitHub
1. أنشئ Repository جديد وارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** وانتظر انتهاء `build`.
3. حمّل الـ jar من **Artifacts** ← `Server-Graphics-and-Quality-Settings`.
4. ضعه في `mods` مع Fabric Loader و Fabric API لنسخة 1.21.11.
